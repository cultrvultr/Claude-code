# Fortnite Map Acquisition Calculator

A web application that helps investors calculate ROI and earn-back periods for Fortnite Creative map acquisitions.

## Features

- Calculate investment earn-back periods (simple and realistic)
- Model CCU (Concurrent Users) decay over time
- Track brand deal contributions
- 36-month earnings projection table
- Visual charts for earnings and CCU trends

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Recharts (visualization)
- Vite (build tool)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
